# Spacemesh

> Spacemesh is a permissionless, proof-of-space-time (PoST) layer-1 blockchain designed to run on ordinary home computers using unused disk space instead of specialized hardware or large stake. Its node software (go-spacemesh) exposes a gRPC API — with a grpc-gateway REST/JSON facade — for reading chain state (accounts, transactions, layers, rewards, activations) and submitting transactions. NOTE: the company's web and hosted-API domains (spacemesh.io, spacemesh.network) are parked/for-sale and the last node release was April 2025; the protocol, node, API design, and tooling remain open source on GitHub but there is no live hosted public API endpoint.

## APIs
- [Spacemesh API (proto + swagger)](https://github.com/spacemeshos/api): gRPC service + message definitions and generated Swagger 2.0 for the node API (services: Account, Transaction, Layer, Reward, Activation, Malfeasance, Network, Node; plus v1 Node/Mesh/GlobalState/Smesher/Tx/Admin/Debug/PoST).
